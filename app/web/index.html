Getting the stream onto a BrightSign

1. Pick an address. Multicast (e.g. 239.192.1.1:5000) lets any number of players and this PC watch the same stream. Unicast (the BrightSign's own IP, e.g. 192.168.1.50:5000) sends to one player only.

2. On the BrightSign (BrightAuthor:connected) add a Video Stream / Streaming state and enter the URL shown on each portal card, e.g. udp://239.192.1.1:5000. For unicast use the port only, e.g. udp://0.0.0.0:5000. Check the exact syntax against your BrightSign OS version's docs.

3. Safe settings for BrightSign: H.264, MPEG-TS, 1920×1080 at 30 or 60 fps, 6–15 Mbps, keyframe every 1–2 seconds, AAC 48 kHz audio, packet size 1316. Keep the stream at a constant bitrate.

4. Network: for multicast, the switch should have IGMP snooping (and a querier) on, or multicast will flood the network. Allow the program through Windows Firewall when Windows asks. If the PC has several network cards, put its IP in Send from NIC IP.

5. Check it: click 📡 Test on any portal to listen for 6 seconds and see what's arriving, or Preview in VLC on a multicast portal to watch exactly what the players receive.

6. No signal when receiving? (a) In Settings, pick the network adapter that is on the video network. Windows often picks Wi-Fi, a VPN or the office network instead. (b) Paste the firewall commands from Settings into Terminal (Admin). (c) Set that network to Private in Windows. (d) Make sure the switch passes multicast (IGMP snooping with a querier).
